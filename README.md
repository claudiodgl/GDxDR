# GDxDR '27: Bridging Graph Drawing and Dimensionality Reduction

Website for the second GDxDR workshop, co-located with [EuroVis 2027](https://eurovis27.github.io/web/) in Stuttgart, Germany (31 May – 4 June 2027).

**Live site:** https://gdxdr.org/2027/

Previous edition: [GDxDR '26](https://sites.google.com/view/gdxdr26/home)

## Files

- `index.html`: sends visitors to the current edition
- `2027/index.html`: the 2027 site (styles and animation included)
- `2027/gdxdr-mark.svg`: browser-tab icon
- `2027/img/`: organizer photos and GDxDR '26 photos

The site is static, so no build step is needed. To preview it, open `2027/index.html` in a browser.
